# KSUX workflow review

KSUX is a Kennesaw State University campus companion for Kennesaw and Marietta. The review traced the documented Student workflows through the Next.js client and route handlers, Convex functions and schema, scheduled jobs, checked-in campus data, and existing test seams. The workspace's [README](README.md), [specification](docs/SPEC.md), [runbook](docs/RUNBOOK.md), [glossary](GLOSSARY.md), and six [architecture decisions](docs/adr/) define the intended behavior.

## Fix verification

- Vitest passed 129 unit and in-process workflow cases across 37 files. All earlier expected failures run as ordinary passing tests. TypeScript, ESLint, the Next.js production build, and Git whitespace checks passed.
- Chromium Playwright passed on Windows against an anonymous local Convex backend. It covered two-tab demo personas, parking, Scrappy SSE, Deal Chat handoff, moderation, reset, cold offline schedule/map reload, and demo cache clearing.
- Hosted SMTP, storage, web push, and credentialed AI remain deployment smoke checks. The Chromium scenario used Judge Demo Mode and local Scrappy grounding. Upload tests exercised WebP decoding and mocked the hosted storage provider.

## Campus data provenance

- **Banner.** The default catalog includes six publicly listed sections, covering CS 3305, SWE 3313, and ME 3101 in Fall 2026 and Spring 2027. It is a curated subset. The checked-in entries contain section numbers, CRNs, published meeting details, and instructor names, with no email addresses. [Verified data](data/ksu-seed/banner-verified.json) · [Official class schedule](https://srs-owlexpress.kennesaw.edu/StudentRegistrationSsb/ssb/term/termSelection?mode=search) · [Example public section listings](https://owlexpress.kennesaw.edu/prodban/bwckctlg.p_disp_listcrse?crse_in=3305&schd_in=E&subj_in=CS&term_in=202608)
- **Events and Clubs.** Localist supplies live Event occurrences when reachable. Engage import is conditional on receiving valid public syndication. The generated Club catalog is limited to fixture deployments. For the official organization directory, KSU directs Students to Owl Life. [KSU Calendar](https://calendar.kennesaw.edu/) · [KSU Student Organizations](https://campus.kennesaw.edu/current-students/student-affairs/involvement/activities/registered-student-organizations/get-involved.php)
- **Dining, shuttle, and study.** Dining reads the official hours page and dated Nutrislice menus. Shuttle and LibCal reads use validated snapshots when available. The app shows unavailable or stale data explicitly. [KSU Dining hours](https://campus.kennesaw.edu/offices-services/dining/hours-locations.php) · [KSU Nutrislice](https://ksu.nutrislice.com/menu/) · [Big Owl Bus](https://campus.kennesaw.edu/offices-services/parking/big-owl-bus/) · [KSU LibCal](https://kennesaw.libcal.com/)
- **Synthetic data.** `includeFixtures: true` enables demonstration Club names and contacts, example Events and RSVPs, course sections and syllabi, sample dining menus and hours, artificial room availability, and simulated shuttle positions and ETAs. Judge Demo Mode creates sample Students, Posts, Chats, Listings, and Study Sessions in each demo workspace. Automated tests use controlled clocks, fixture records, and mock provider responses. [Fixture generator](scripts/harvest-ksu-seed.ts) · [Judge Demo Mode fixture data](convex/demo/fixtures.ts)
- **Static reference data.** The offline GeoJSON has approximate building and Parking Lot footprints, route geometry, and Meetup Spot coordinates. Parking baselines are modeled time-of-day estimates. Classroom and room availability should be verified with the linked campus source. [Offline map data](public/data/) · [Campus reference seed](data/ksu-seed/)

The November 17, 2026 source check returned paginated Localist JSON and a public Engage iCalendar response. The production parsing code normalized published hours and closure ranges for both Dining Halls, loaded dated Nutrislice stations for both, and accepted 19 Passio vehicle positions. Live LibCal, hosted UploadThing, SMTP, push, and credentialed AI responses were outside that check.
