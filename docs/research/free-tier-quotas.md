# Zero-Cost ($0) Infrastructure Quota & Trap Evaluation for KSUX

> **Issue**: [`Control707/KSUX#3`](https://github.com/Control707/KSUX/issues/3) — *Evaluate zero-cost hosting, realtime database, storage, and auth quotas*  
> **Verification Date**: November 2026 (all figures verified directly against first-party pricing, limits, and documentation pages)  
> **Constraint**: Strictly **$0 spend**, **no paid plan**, **no credit card required** (any service requiring a card on file or a paid custom domain is explicitly flagged), supporting all KSUX capabilities across the `Kennesaw` and `Marietta` `Campuses` during a 5-day build and live hackathon evaluation.

---

## 1. Executive Summary & Key Findings

Running KSUX's full feature set — real-time `Feed`, 1:1 `Direct Messages (DMs)`, `Group Chats` (for friends, `Clubs`, and `Course Hubs`), Marketplace `Listings` and `Deal Chats` with `Meetup Spot` coordination, live `Parking Lot` / `Parking Report` updates, `Study Room` / `Study Session` coordination, `Events`, `Shuttle Routes`, `Scrappy` AI queries, media image uploads, `@students.kennesaw.edu` / `@kennesaw.edu` verification, `Judge Demo Mode`, and scheduled KSU public data syncs — is **100% achievable at $0 with zero credit cards and zero custom domain purchases**, provided the architecture avoids seven critical free-tier traps verified in primary vendor documentation:

1. **Supabase Built-In Auth SMTP Hard Block**: Supabase's default SMTP server is not merely capped at **2 emails/hour** — it **refuses delivery (`Email address not authorized`) to any address outside the Supabase Organization's Team tab** ([Supabase Custom SMTP Docs](https://supabase.com/docs/guides/auth/auth-smtp)). Leaving default SMTP enabled completely breaks `.edu` sign-up for external `Students`.
2. **Resend & `@convex-dev/auth` Custom Domain Trap**: Resend's Free tier (`3,000 emails/mo`, `100 emails/day`) **requires a verified custom DNS domain (~$10/yr)**; its sandbox sender (`onboarding@resend.dev`) returns `HTTP 403` for every recipient except the Resend owner's own email ([Resend Domain Docs](https://resend.com/docs/dashboard/domains/introduction), [Resend 403 Error Guide](https://resend.com/docs/knowledge-base/403-error-resend-dev-domain)). Built-in `@convex-dev/auth` v2 `emailPassword` is coupled to `@convex-dev/resend` and inherits this exact custom-domain requirement ([Convex Auth Email Docs](https://docs.convex.dev/auth/convex-auth/methods/email-password)).
3. **Clerk Triple Trap (Paid Allowlist + Production Domain + 100-Student Dev Cap)**: Clerk's Hobby plan (`$0`, `50,000 MRU`) gates **Allowlist domain restrictions** (`*@students.kennesaw.edu`, `*@kennesaw.edu`) behind the **paid Pro plan ($20/mo)** in Production ([Clerk Restricting Access Docs](https://clerk.com/docs/guides/secure/restricting-access)), **requires owning a custom DNS domain** to deploy a Production instance ([Clerk Production Deployment Docs](https://clerk.com/docs/guides/development/deployment/production)), and caps `Development` instances on `*.vercel.app` / `*.pages.dev` at **100 total `Students`**, adds `[Development]` banners, and passes session tokens in URL query strings ([Clerk Environments Docs](https://clerk.com/docs/guides/development/managing-environments)).
4. **Domain-Free `.edu` Verification Winner — Personal Gmail SMTP (`smtp.gmail.com`) + 6-Digit OTP + `Judge Demo Mode`**: A free Google Gmail inbox with 2-Step Verification and an App Password sends up to **500 messages per rolling 24 hours** over `smtp.gmail.com:465` (SSL/TLS) or `:587` (STARTTLS) at **$0 with no credit card and no custom domain**, with native Google SPF/DKIM/DMARC alignment ([Google Gmail IMAP/SMTP Docs](https://developers.google.com/workspace/gmail/imap/imap-smtp)). Crucially, KSUX should send **6-digit OTP codes** rather than clickable Magic Links so KSU's Microsoft Exchange / Defender Safe Links scanner cannot pre-fetch and burn one-time URLs, and pair `.edu` verification with **`Judge Demo Mode`** so hackathon evaluators have instant one-click access without needing a `.edu` inbox.
5. **KSU Microsoft Entra ID OAuth Consent Trap**: Both `kennesaw.edu` and `students.kennesaw.edu` resolve to KSU's Microsoft Entra ID tenant (`45f26ee5-f134-439e-bc93-e6c7e33d61c2`) ([KSU OIDC Discovery](https://login.microsoftonline.com/kennesaw.edu/v2.0/.well-known/openid-configuration)), where enterprise user-consent restrictions typically block unverified external OAuth Client IDs with an *"Approval required"* screen ([Microsoft Entra Consent Docs](https://learn.microsoft.com/en-us/entra/identity/enterprise-apps/user-admin-consent-overview)). Do not rely on Microsoft OAuth as the primary `.edu` gate.
6. **Credit-Card-Gated Storage & Compute Traps (Cloudflare R2 & Firebase Spark)**:
   - **Cloudflare R2** (`10 GB/mo`, `$0` egress) **requires adding a valid payment method on file** (credit card/PayPal/Apple Pay; prepaid/gift cards rejected) and runs payment preauthorizations ([Cloudflare R2 Get Started](https://developers.cloudflare.com/r2/get-started/), [Cloudflare Billing Policy](https://developers.cloudflare.com/billing/understand/billing-policy/)).
   - **Firebase Spark Plan** (`$0`, no card) **blocks both Cloud Storage for Firebase (including the default bucket, since Sept 2024) and Cloud Functions for Firebase**, requiring an upgrade to the credit-card-linked Blaze plan ([Cloud Storage for Firebase FAQ](https://firebase.google.com/docs/storage/faq-and-troubleshooting), [Firebase Pricing Plans](https://firebase.google.com/docs/projects/billing/firebase-pricing-plans)), and caps Realtime Database at **100 simultaneous connections** ([Firebase RTDB Limits](https://firebase.google.com/docs/database/usage/limits)).
7. **Cron Frequency Trap on Vercel Hobby**: Legacy `vercel.json` Cron Jobs on Vercel Hobby only run **once per day** with **±59-minute jitter** (sub-daily cron expressions fail build deployment!) ([Vercel Cron Usage & Pricing](https://vercel.com/docs/schedules/cron-jobs/usage-and-pricing)), while Vercel's new beta Schedules run at most **every 15 minutes** with mandatory 15-minute jitter ([Vercel Schedules Limits](https://vercel.com/docs/schedules/limits)). Offloading scheduled KSU feed syncs to **Convex Cron Jobs** (`crons.interval` down to 1 second), **Supabase Cron** (`pg_cron` down to 1 minute/second), or **Cloudflare Workers Cron Triggers** (5 triggers, 1-minute precision) eliminates this bottleneck completely.

### Hosting Takeaways for KSUX
* **Vercel Hobby** gives zero-friction Next.js/React deployment with **5-minute Node.js function timeouts** (ideal for `Scrappy` streaming LLM calls), provided KSUX:
  1. Keeps `Control707/KSUX` under a personal GitHub owner (`Control707`) rather than transferring it to a GitHub Organization.
  2. Processes **zero real-money payments or ads** (KSUX Marketplace `Listings` coordinate peer-to-peer campus `Meetup Spot` handoffs inside `Deal Chats`, which is non-commercial).
  3. **Does not use `vercel.json` Cron Jobs** for KSU `Shuttle Route` / `Parking Lot` / `Event` feed syncs — run scheduled syncs in **Convex Crons**, **Supabase `pg_cron`**, **Cloudflare Workers Cron Triggers**, or **Upstash QStash Free** (`1,000 messages/day`, 10 schedules; [Upstash QStash Pricing](https://upstash.com/pricing/qstash)).
* **Cloudflare Pages / Workers Free** offers **unlimited static bandwidth** and **true 1-minute Cron Triggers**, but its **10 ms CPU limit per invocation** means SSR-heavy Next.js bundles (`@opennextjs/cloudflare`) or CPU-heavy HTML scrapers/password hashers inside Workers can trip `Error 1102`. It excels when hosting a Vite/React SPA PWA backed by Convex or Supabase, or as a lightweight standalone `scheduled()` KSU feed poller fetching JSON APIs (since `fetch()` network wait time does not count against the 10 ms CPU budget).

### Deep-Dive on Realtime Gotchas for KSUX's 10 Capabilities
* **Why Firebase Spark Is Disqualified for KSUX**: Cloud Storage for Firebase now requires linking a paid Blaze Cloud Billing card even for the default bucket ([Cloud Storage FAQ](https://firebase.google.com/docs/storage/faq-and-troubleshooting)), Cloud Functions (needed for scheduled KSU feed syncs and server-side OTP logic) also requires Blaze, and Firestore's **50,000 document reads/day** can be exhausted in under an hour if 50 `Students` scroll a 50-item `Feed` and chat in `Group Chats` (each snapshot reload reads every matched document).
* **Why Neon + Upstash Adds Unnecessary Friction**: Neon's mandatory **5-minute scale-to-zero** introduces noticeable wake-up latency during live hackathon demos if a judge pauses between views, and running a 1-minute KSU transit poller keeps Neon awake 24/7 (`0.25 CU × 720 hrs = 180 CU-hrs/mo`, exceeding the 100 CU-hr monthly cap in ~16.6 days, though survivable inside a 5-day sprint). Worse, neither Neon (beta live queries) nor Upstash Redis offers mature browser WebSocket fan-out + presence comparable to Convex or Supabase.
* **Convex Free vs. Supabase Free Head-to-Head**:
  - **Concurrency**: Convex Free supports **1,000 concurrent WebSocket sessions** vs. Supabase Free's **200 concurrent connections**. If 120 `Students` and hackathon judges open KSUX on both laptop and phone simultaneously (240 tabs), Supabase Free hits `too_many_connections` whereas Convex has 4× headroom.
  - **Throughput & Read Cost Trap**: On Convex, **every reactive query re-evaluation pushed to subscribed clients counts toward the 1,000,000 function calls/month and 1 GB/month DB I/O limits** ([Convex Limits](https://docs.convex.dev/production/state/limits)). KSUX **must** define strict compound indexes (`by_campus_and_created`, `by_conversation`) and paginate `.take(25)` / `.paginate()` — never `.collect()` an entire `posts` or `messages` table! On Supabase, `postgres_changes` evaluates Row-Level Security (RLS) per subscribed `Student` on shared CPU; for high-traffic `Group Chats` and `Deal Chats`, pairing Postgres `INSERT`s with **Supabase Realtime Broadcast** avoids RLS fan-out bottlenecks and gives **2,000,000 messages/month** at up to **100 msgs/sec**.

### Mandatory `.edu` Auth Design Rules for KSUX
1. **Use 6-Digit Email OTP Codes, NEVER Clickable Magic Links**: University Microsoft 365 / Exchange Defender ("Safe Links") automatically pre-fetches clickable links inside incoming `@students.kennesaw.edu` and `@kennesaw.edu` emails, **consuming one-time Magic Link tokens before the `Student` clicks them**. In addition, clicking an email link on iOS/Android opens the mail client's in-app webview rather than the installed KSUX PWA. A 6-digit numeric OTP typed directly into KSUX solves both problems completely.
2. **Enforce Suffix Validation on Both Client and Backend**: Reject any email not matching `/^[^@\s]+@(students\.)?kennesaw\.edu$/i` before dispatching an OTP **and** inside the database mutation / Supabase Auth Hook so `Students` cannot bypass UI validation via API calls. Also tag each verified `Student` profile with role affiliation (`@students.kennesaw.edu` vs. `@kennesaw.edu`) if helpful.
3. **First-Class `Judge Demo Mode` Bypass**: Wire a one-click **"Enter Judge Demo Mode"** button on the auth screen that signs into a pre-seeded KSUX `Student` session (complete with sample `Campus` selection, `Posts`, `Direct Messages`, `Group Chats`, `Listings`, and `Deal Chats`) with **zero SMTP calls**. This protects the 500/day Gmail SMTP quota and guarantees zero-friction judging.

> **Client-Side WebP Compression Rule (Applies to Every Stack)**: Modern iPhone/Android cameras capture 4–8 MB HEIC/JPEG photos. ## 6. Two Concrete $0 Reference Stacks (Zero Credit Card, Zero Paid Domain)

### Reference Stack A (Recommended Primary): Vercel Hobby + Convex Free + UploadThing Free + Gmail SMTP OTP

Best for **maximum real-time responsiveness, 5× higher WebSocket concurrency, zero inactivity pausing, and fastest 5-day TypeScript velocity** across `Feed`, `Direct Messages`, `Group Chats`, `Deal Chats`, `Parking Reports`, `Study Sessions`, and `Scrappy`.

| Layer | Service ($0, No Card, No Domain) | Exact Free Allocation Used | How It Powers KSUX |
| :--- | :--- | :--- | :--- |
| **Frontend PWA & Edge Delivery** | **Vercel Hobby** (`*.vercel.app`) | 100 GB Fast Data Transfer, 1M Function invocations, 300s function max duration | Hosts installable Next.js / React PWA; personal `Control707/KSUX` repo deploys automatically on `git push`. |
| **Realtime DB, Chat, Search & Crons** | **Convex Free (S16)** | **1,000 concurrent sessions**, 1M function calls/mo, 0.5 GB DB, 1 GB DB I/O, 20 GB-hrs Node/V8 Actions, Full-Text + Vector Search, native `convex/crons.ts` | Reactive queries auto-update `Feed`, `Direct Messages`, `Group Chats`, `Deal Chats`, `Parking Reports`, and `Study Sessions` over a single multiplexed WebSocket; `convex/crons.ts` syncs public KSU `Shuttle Routes`, `Parking Lots`, and `Events` every **2–5 minutes** (bypassing Vercel Hobby's 1/day cron cap!); built-in text/vector search grounds `Scrappy`. |
| **`.edu` Verification & `Judge Demo Mode`** | **Custom Convex OTP (`emailOtps` table) + Gmail SMTP (`smtp.gmail.com:465`)** | **500 OTP emails/day**, $0 domain cost, native Google DKIM/SPF/DMARC | Convex `"use node"` `internalAction` validates `@students.kennesaw.edu` / `@kennesaw.edu`, hashes a 6-digit OTP (10-min expiry, 5-attempt cap), and sends via `nodemailer` + Gmail App Password; one-click **`Judge Demo Mode`** mints a pre-seeded `Student` session with zero emails sent. |
| **Media Uploads (`Posts` & `Listings`)** | **UploadThing Free ("2GB App")** (or **Cloudinary Free**) + Client WebP Compression | **2 GB storage**, **unlimited bandwidth/egress** (or 25 Cloudinary credits) | Offloads all `Post`, `Listing`, `Club`, and avatar media so Convex's 1 GB/mo file egress and 1M function call quotas remain 100% dedicated to JSON/realtime state. |

**Stack A Mandatory Engineering Guardrails**:
1. Every Convex query **must** use `.withIndex(...)` and bounded `.take(N)` / `.paginate()` (never `.collect()` unbounded tables) so reactive invalidations stay tiny against the **1M function calls/mo** and **1 GB/mo DB I/O** limits.
2. Compress images client-side to `≤200 KB` WebP before uploading to UploadThing.
3. Keep `Control707/KSUX` under a personal GitHub user account and include zero commercial payment/ad flows on Vercel Hobby.
