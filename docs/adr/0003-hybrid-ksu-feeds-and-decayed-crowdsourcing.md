# Server-synced public KSU snapshots layered with recency-decayed `Student` crowdsourcing and stateless `.ics` onboarding

OwlSide hydrates campus daily-life state from server-synced normalized snapshots of public Kennesaw State feeds (`calendar.kennesaw.edu` Localist JSON, `kennesaw.campuslabs.com/engage` syndication and active organization directory, `kennesaw.libcal.com` 30-minute `Study Room` availability grids, `ksu.api.nutrislice.com` + `hours-locations.php` `Dining Venue` menus/hours, `maps.kennesaw.edu/xml/CL_kennesaw.xml` GeoJSON polygons, Passio GO GTFS/GTFS-RT `Shuttle Routes`, and `srs-owlexpress.kennesaw.edu` Banner 9 `Fall 2026`/`Spring 2027` catalog sections + lazy Simple Syllabus) paired with `10–45m` time-decayed `Student` crowdsourcing, LibCal `/space/{eid}` reservation deep-links, Banner 9 hourly class-load priors, and stateless `.ics` file imports rather than `owllife.kennesaw.edu`, automated LibCal booking, live deck sensors, or server-polled D2L `.ics` URLs. KSU repointed `owllife.kennesaw.edu` (`HTTP 301`) to SAML-gated Suitable (`401 Unauthorized`), locks LibCal checkout and Owl Express/D2L personal schedules behind NetID/Duo SSO, and publishes zero live `Parking Lot` occupancy or `Dining Venue` wait-time telemetry (`parking-pulse.php` is static histograms and T2 Flex sits behind Queue-it + Duo). Decaying crowdsourced `Parking Reports` (`45m` fullness, `10m` broadcast `Spot Opening` pings), `Dining Venue` line checks (`30m`), walk-in `Study Room` vibes (`45m`), and stop pulses (`15m`) into labeled class-density/meal-rush baselines — backed by stale-while-revalidate Convex snapshots, checked-in KSU seed data, and boot-relative `Judge Demo Mode` timestamps — delivers truthful real-time utility with zero KSU IT approvals, zero stored LMS credentials, and zero broken demos during upstream maintenance.
