# Convex Free + Vercel Hobby + UploadThing + 3-tier `Scrappy` stack with $0 quota guardrails

KSUX runs on a Next.js App Router PWA on Vercel Hobby (`*.vercel.app`), Convex Free (S16) for reactive database state, search, and `convex/crons.ts` jobs, UploadThing Free (`2 GB`, unlimited egress) for EXIF-stripped WebP images, `MapLibre GL JS` + `OpenFreeMap` for card-free campus maps, custom Convex `emailOtps`/`studentSessions` tables over Gmail App-Password SMTP, and a 3-tier OpenAI-compatible `Scrappy` router (Groq `openai/gpt-oss-120b`/`openai/gpt-oss-20b` primary, PII-stripped Gemini `gemini-3.5-flash-lite`/`gemini-4-hydrogen` overflow, Cloudflare Workers AI `@cf/google/gemma-4-26b-a4b-it` fallback + selective `@cf/google/embeddinggemma-2` vectors on `Posts`, `Listings`, `Events`, and `Clubs`). Built-in `@convex-dev/auth` v2 requires `@convex-dev/resend` (~$10 custom DNS domain), Vercel Hobby rejects sub-daily `vercel.json` crons, Supabase Free caps Realtime at 200 connections and auto-pauses after 7 days, and Mapbox/Google Maps/Cloudflare R2/Firebase Storage require credit cards on file. To stay well inside Convex Free's `1M` monthly function calls, `1 GB` DB I/O, and `0.5 GB` DB/index storage, KSUX enforces mount-scoped indexed pagination, polls live Passio GO `Shuttle Route` bus GPS directly in the browser via `CORS: *`, answers `@scrappy` mentions in `Feed` `Posts` and replies via a 2-write async Convex Action (while streaming 1:1 `Ask Scrappy` over HTTP SSE), serves static campus GeoJSON from `/public/data/`, and purges expired `Judge Demo Mode` UploadThing files via `UTApi.deleteFiles`.
